Tarjetas regalo

Las que se reservan en la web llegan aquí como «reservada» y te avisa el móvil. Cuando la clienta pase a pagarla, márcala como pagada (desde ese día vale un año). Cuando la usen, descuenta lo gastado.

Servicios y precios

Lo que pongas aquí sale en la web al momento. Si un servicio no tiene precio, en la web no se muestra ninguno.

Equipo y horarios
